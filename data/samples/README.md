# Sample Reports

This directory contains curated sample reports generated by RouteBench.

## Generating Sample Reports

To generate sample reports, run the full pipeline with OSRM and an Anthropic API key:

```bash
# Generate a synthetic fleet exercising all diagnosis categories
uv run python scripts/generate_synthetic.py --n-routes 10

# Run the pipeline
uv run python scripts/run_local.py data/synthetic/sample.csv

# Copy the outputs here
cp data/sessions/*/report.html data/samples/v1/report.html
cp data/sessions/*/report.pdf data/samples/v1/report.pdf
```

Once committed, these are served at `/samples/v1/report.html` by the FastAPI app.
